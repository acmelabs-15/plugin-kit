## Knowledge graph

This project uses Brain with `CODE` memory mode. Knowledge-graph notes live in
`docs/` inside this repository and are tracked in git:

| Folder | Contents |
| :-- | :-- |
| `docs/analysis/` | ANALYSIS notes |
| `docs/decisions/` | ADR notes |
| `docs/planning/` | PLAN and PRD notes |
| `docs/sessions/` | SESSION notes |
| `docs/specs/` | SPEC subtrees (requirements, design, tasks) |
